# FindIt AI — Application Route Directory

TanStack Start uses **file-based routing**. Every `.tsx` file in this directory defines an application route. The app shell layout is defined in `src/routes/__root.tsx`.

---

## 🗺️ Route Inventory

| Route File | Path | Description |
| :--- | :--- | :--- |
| `index.tsx` | `/` | Home landing page with high-level search and quick actions. |
| `login.tsx` | `/login` | User login screen with JWT authentication. |
| `register.tsx` | `/register` | Account registration with campus details. |
| `dashboard.tsx` | `/dashboard` | User dashboard showing active reports, claim statuses, and stats. |
| `discover.tsx` | `/discover` | Explore and search lost and found items with category/status filters. |
| `feed.tsx` | `/feed` | Recent campus activity stream of lost & found posts. |
| `report.tsx` | `/report` | Multi-step form to report a lost or found item with photo uploads. |
| `scan.tsx` | `/scan` | Full document & ID scanning and OCR interface. |
| `quick-scan.tsx` | `/quick-scan` | Camera-based rapid OCR scanning for found student/faculty ID cards. |
| `matches.tsx` | `/matches` | AI match review screen showing confidence scores and similarity reasons. |
| `item.$id.tsx` | `/item/:id` | Detailed item information page (dynamic segment `$id`). |
| `claim.$id.tsx` | `/claim/:id` | Multi-round AI ownership verification questionnaire powered by Gemini. |
| `notifications.tsx` | `/notifications` | Real-time notifications for matches, claims, and chat messages. |
| `profile.tsx` | `/profile` | Current user profile, contact details, and submitted items. |
| `profile.$id.tsx` | `/profile/:id` | Public profile view with user privacy filters applied. |
| `settings.tsx` | `/settings` | Notification preferences, privacy masks, and account settings. |
| `__root.tsx` | App Shell | Global layout wrapping all routes (Head, Auth, Navigation, Toasts). |

> **Note**: `routeTree.gen.ts` is auto-generated by `@tanstack/router-plugin`. Do not edit it directly.
